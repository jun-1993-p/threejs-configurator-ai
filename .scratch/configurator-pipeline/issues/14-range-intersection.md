# 14: 범위 교집합

**What to build:** 슬라이더 범위가 치수 규칙 ∩ 정보 입력의 범위 메모 ∩ 스윕 범위 안에서 정해지고, 근거가 된 치수 규칙이 명세의 `source`에 남는다(ADR-0009). 교집합이 비면 범위를 지어내지 않고 운영자에게 알린다.

**Blocked by:** 04 (수치 검증과 검증 피드백 루프)

**Status:** ready-for-agent

- [ ] 치수 규칙 저장소가 있고, 부위별 범위와 출처를 담는다
- [ ] 명세의 범위가 세 범위의 교집합을 벗어나면 명세 검사가 실패한다
- [ ] `source`가 치수 규칙에 없는 항목이면 실패한다
- [ ] 교집합이 비면 `no_range_intersection` 피드백이 나오고 운영자에게 표시된다
- [ ] 슬라이더 기본값이 업로드한 Fusion 모델의 현재 값인지 검사한다
