# 18: UI 스타일 선택

**What to build:** AI가 정해진 UI 스타일 목록에서 색·글꼴·슬라이더 모양을 고르고, 고정 코어가 그 스타일로 구성기를 띄운다. 스타일은 목록 밖의 값을 만들 수 없다(ADR-0001).

**Blocked by:** 15 (LiteLLM 포트와 실제 명세 작성)

**Status:** ready-for-agent

- [ ] UI 스타일 저장소에 스타일 목록이 있다
- [ ] UI 스타일 단계가 목록 안의 스타일 하나를 JSON Schema 형식으로 고른다
- [ ] 목록에 없는 스타일을 고르면 다음 단계로 가지 않는다
- [ ] 고정 코어가 고른 스타일로 색·글꼴·슬라이더 모양을 적용한다
