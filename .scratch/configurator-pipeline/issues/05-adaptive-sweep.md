# 05: 적응형 스윕과 범위 축소

**What to build:** 애드인이 업로드 때 비선형 구간에서만 샘플을 늘린다. 5점 균등에서 시작해 구간 중간 검증점의 오차가 합격선을 넘는 구간만 반으로 나누며 최대 17점까지 늘리고, 그래도 넘으면 그 파라미터를 실패로 보고한다. Fusion 재계산이 실패하는 지점에서는 스윕 범위를 줄인다(ADR-0007).

**Blocked by:** 01 (애드인 업로드와 녹화), 04 (수치 검증과 검증 피드백 루프)

**Status:** ready-for-agent

- [ ] 애드인 안의 1D 보간 오차 계산이 변형 엔진의 단독 스윕 보간과 같은 규칙을 쓴다
- [ ] 선형 파라미터는 5점에서 멈추고, 경사·원형 패턴처럼 비선형인 파라미터는 해당 구간만 샘플이 늘어난다
- [ ] 17점으로도 합격선을 못 맞춘 파라미터는 실패로 보고되어 슬라이더 후보에서 빠진다
- [ ] 재계산이 실패하는 값이 있으면 그 지점 안쪽으로 스윕 범위가 줄어들고, 줄어든 범위가 업로드 묶음에 담긴다
- [ ] 비선형 파라미터가 있는 실제 상품의 녹화본이 추가된다
