# 07: 여러 슬라이더 덧셈

**What to build:** 쇼핑몰 고객이 여러 슬라이더를 함께 움직이면, 변형 엔진이 각 단독 스윕의 꼭짓점 이동량을 더해서 섞고(ADR-0004), 고정 코어는 명세의 슬라이더 개수만큼 UI를 자동으로 구성한다.

**Blocked by:** 03 (파이프라인 실행기 관통)

**Status:** ready-for-agent

- [ ] 변형 엔진이 슬라이더 여러 개의 이동량을 더해 꼭짓점을 낸다
- [ ] 슬라이더 하나만 움직이면 단독 스윕 보간과 결과가 같다
- [ ] 고정 코어가 명세의 슬라이더 개수만큼 슬라이더를 만든다
- [ ] 서로 영향이 없는 두 슬라이더를 함께 움직인 결과가 녹화된 Fusion 형상과 합격선 안에서 맞는 엔진 테스트가 있다
