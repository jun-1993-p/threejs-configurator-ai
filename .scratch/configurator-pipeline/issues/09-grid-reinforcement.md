# 09: 격자 보강

**What to build:** 덧셈이 틀리는 슬라이더 쌍은 먼저 명세 수정으로 재시도하고, 그래도 안 되면 그 쌍만 3×3 격자 샘플로 보강해 변형 엔진이 격자 보간으로 섞는다(ADR-0008). 상품당 2쌍까지 허용한다.

**Blocked by:** 08 (추가 샘플 요청과 교차 검증)

**Status:** ready-for-agent

- [ ] 명세 수정 재시도 뒤에도 교차 검증에 실패한 쌍에 대해 서버가 3×3 격자 샘플을 요청한다
- [ ] 변형 엔진이 격자 보강 쌍은 격자 보간으로, 나머지는 덧셈으로 섞는다
- [ ] 격자 보강 쌍은 명세가 아니라 애드인 결과에 담긴다
- [ ] 보강이 필요한 쌍이 2쌍을 넘으면 검증 피드백이 나온다
- [ ] 전체 폭·서랍 폭처럼 서로 영향을 주는 쌍의 녹화본으로 엔진 테스트와 경계 1 테스트가 있다
