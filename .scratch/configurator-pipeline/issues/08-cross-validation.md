# 08: 추가 샘플 요청과 교차 검증

**What to build:** 검증 중에 서버가 애드인에 교차 검증 샘플(슬라이더 쌍의 모서리 조합)을 요청하고, 애드인은 업로드부터 최종 승인까지 연결된 채로 응답한다(ADR-0013). 덧셈이 합격선을 넘는 쌍은 검증 피드백으로 돌아간다. 연결이 끊기면 실패로 기록하지 않고 "Fusion 연결 필요" 상태로 기다린다.

**Blocked by:** 04 (수치 검증과 검증 피드백 루프), 07 (여러 슬라이더 덧셈)

**Status:** ready-for-agent

- [ ] 서버가 파라미터 값 묶음으로 추가 샘플을 요청하고, 애드인이 업로드 묶음의 샘플과 같은 형식으로 답한다
- [ ] 슬라이더 쌍마다 모서리 조합 교차 검증 샘플을 받아 덧셈 결과와 비교한다
- [ ] 덧셈 오차가 합격선을 넘으면 해당 쌍을 가리키는 검증 피드백이 나온다
- [ ] 애드인 연결이 끊기면 검증이 멈추고 "Fusion 연결 필요"가 표시되며, 다시 연결되면 이어서 진행한다
- [ ] Fusion 연결 포트를 녹화 응답으로 바꿔 끼운 경계 1 테스트가 있다
