# 01: 애드인 업로드와 녹화

**What to build:** 운영자가 Fusion에서 CAD 애드인을 실행하면, 애드인이 서버 연결을 시험한 뒤 모델의 파라미터와 부품, 스윕을 업로드 묶음으로 보낸다. 서버는 묶음을 받아 저장하고, 같은 묶음을 테스트 데이터로 녹화할 수 있다. 이 티켓에서 정한 업로드 묶음 형식을 뒤의 모든 티켓이 쓴다(ADR-0002, 0006, 0007).

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 서버 연결 시험이 실패하면 스윕을 시작하지 않고 운영자에게 알린다
- [ ] 업로드 묶음에 파라미터마다 이름·값·수식·사용자 파라미터 여부가 담긴다
- [ ] 업로드 묶음에 부품(Fusion 컴포넌트 단위, 컴포넌트가 없으면 바디 단위)과 부품 이름, 부품에 속한 면이 담긴다
- [ ] 사용자 파라미터마다 기본값 ±50% 범위에서 5점 균등(최소·¼·½·¾·최대)으로 단독 스윕한다
- [ ] 샘플마다 꼭짓점을 메쉬 출력이 아니라 면별 (u,v) 격자로 찍고, 같은 면 구성이면 샘플끼리 꼭짓점 수가 같다
- [ ] 서버가 업로드 묶음을 받아 저장하고, 녹화본으로 내보낼 수 있다
- [ ] stool1 또는 실제 상품 하나로 만든 녹화본이 있고, 실제 상품 데이터는 공개 저장소에 올라가지 않는 위치에 둔다
