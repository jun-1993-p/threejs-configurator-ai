# 03: 파이프라인 실행기 관통

**What to build:** 상품 하나를 업로드 묶음과 정보 입력, 사람 결정 각본으로 넣으면, 10단계가 코드에 고정된 순서로 진행되어 구성기 결과물이 제출된다(ADR-0014). 이 단계의 AI는 각본대로 답하는 가짜이고, 최종 승인은 승인만 지원한다. 바깥 의존은 Fusion 연결·AI 모델·저장소 세 포트로만 접근한다(테스트 경계 1).

**Blocked by:** 02 (녹화 묶음으로 구성기 띄우기)

**Status:** ready-for-agent

- [ ] 실행기가 업로드 → 정보 입력 → 후보 제시 → 후보 선택 → UI 스타일 → 명세 작성 → 조립 → 검증 → 최종 승인 → 제출·기록 순서로만 진행한다
- [ ] AI 모델 포트를 각본 가짜로 바꿔 끼울 수 있고, 저장소 포트는 메모리 구현으로 바꿔 끼울 수 있다
- [ ] 명세가 JSON Schema 검사를 통과하지 못하면 조립으로 가지 않는다
- [ ] 최종 승인에서 승인하면 고정 코어·명세·스윕 데이터로 된 결과물이 제출된다
- [ ] 상품 하나의 단계 전이가 처리 기록으로 남는다
- [ ] 녹화본 하나로 업로드부터 제출까지 도는 경계 1 테스트가 있다
