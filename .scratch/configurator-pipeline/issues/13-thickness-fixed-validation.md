# 13: 두께 고정 실측과 두께 교차 검증

**What to build:** 슬라이더를 움직이는 동안 고른 두께가 변하지 않는지 형상으로 실측하고, 두께 후보와 각 슬라이더를 함께 바꾼 조합도 교차 검증한다. 자식 수식에 두께가 비율로 섞인 경우도 잡는다.

**Blocked by:** 12 (두께 선택)

**Status:** ready-for-agent

- [ ] 단독 스윕 전체에서 각 부품의 판재 두께 실측이 변하면 `thickness_change` 피드백이 나온다
- [ ] 피드백이 "슬라이더 X가 부품 Y의 두께를 바꿈" 형태로 원인을 가리킨다
- [ ] 두께 후보마다 각 슬라이더와의 교차 검증 샘플을 받아 덧셈을 확인하고, 실패하면 격자 보강 규칙을 따른다
- [ ] 두께가 수식에 섞인 녹화본으로 경계 1 테스트가 있다
