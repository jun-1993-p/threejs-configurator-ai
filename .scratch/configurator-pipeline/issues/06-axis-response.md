# 06: 축 반응 검증

**What to build:** 명세에 슬라이더마다 형태 변경 부품과 위치 이동 부품을 선언하고, 검증이 단독 스윕에서 실제 축 반응과 비교한다. 한 축에 슬라이더가 여러 개여도(전체 폭·서랍 폭) 각 슬라이더가 맡은 부품만 움직이는지 부품 단위로 확인한다.

**Blocked by:** 04 (수치 검증과 검증 피드백 루프)

**Status:** ready-for-agent

- [ ] 명세의 슬라이더에 `affects.shape`, `affects.move`가 있다
- [ ] 형태 변경 부품의 해당 축 치수가 바뀌지 않으면 실패한다
- [ ] 선언되지 않은 부품이나 위치 이동 부품의 치수가 바뀌면 `unexpected_shape_change`로 실패한다
- [ ] 슬라이더의 축이 아닌 다른 축(D·H 등) 치수가 바뀌면 실패한다
- [ ] 피드백은 부품 이름과 고칠 명세 위치를 담는다
- [ ] 수치 검증을 통과한 뒤에만 축 반응 검증이 돈다
- [ ] 한 축에 슬라이더 두 개가 있는 녹화본으로 경계 1 테스트가 있다
