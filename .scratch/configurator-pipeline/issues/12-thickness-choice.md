# 12: 두께 선택

**What to build:** 명세에 두께 선택을 쓸 수 있고, 고객은 구성기의 두께 슬롯에서 표준 두께 목록의 앞뒤 한 칸 중 하나를 고른다(ADR-0010). 두께 후보 형상은 추가 샘플 요청으로 받고, 변형 엔진은 후보를 사이 값 없이 바꿔 끼운 뒤 다른 슬라이더와 덧셈으로 섞는다.

**Blocked by:** 08 (추가 샘플 요청과 교차 검증)

**Status:** ready-for-agent

- [ ] 고정 코어에 표준 두께 목록(3·6·9·12·15·18·24·30 mm)이 있다
- [ ] 명세의 `thickness[].options`가 기본 두께의 앞뒤 한 칸이 아니면 명세 검사가 실패한다(목록 끝은 후보 2개)
- [ ] `thickness[].ids`로 묶인 파라미터의 기본 두께가 다르면 실패한다
- [ ] `fixed`의 파라미터가 어떤 슬라이더의 `children`에 있으면 실패한다
- [ ] 서버가 두께 후보 형상을 애드인에 요청해 받는다
- [ ] 고정 코어가 명세의 두께 선택마다 슬롯을 만들고, 고르면 형상이 그 두께로 바뀐다
