# 02: 녹화 묶음으로 구성기 띄우기

**What to build:** 손으로 쓴 슬라이더 1개짜리 명세와 녹화된 업로드 묶음을 넣으면, 변형 엔진이 단독 스윕 샘플 사이를 보간하고, 고정 코어가 그 결과를 쇼핑몰에 넣을 div 하나짜리 구성기로 띄운다. 쇼핑몰 고객은 슬라이더를 움직여 형태가 매끄럽게 바뀌는 것을 본다. 변형 엔진은 브라우저와 Node에서 같은 라이브러리로 동작한다(테스트 경계 2).

**Blocked by:** 01 (애드인 업로드와 녹화)

**Status:** ready-for-agent

- [ ] 명세(`docs/spec-schema.md` 구조)와 스윕 데이터, 슬라이더 값을 받아 꼭짓점을 내는 변형 엔진이 있다
- [ ] 같은 엔진이 브라우저와 Node 양쪽에서 같은 결과를 낸다
- [ ] 샘플 값에서는 엔진 결과가 녹화된 Fusion 형상과 일치한다
- [ ] 고정 코어가 명세에서 슬라이더를 읽어 UI를 자동으로 구성하고, 기본값은 명세의 `default`이다
- [ ] 결과물이 div 하나와 JS 번들로 나와 빈 HTML 페이지에 붙여 동작한다
- [ ] Node에서 도는 엔진 테스트가 녹화본을 입력으로 쓴다
