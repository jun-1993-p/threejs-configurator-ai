# 19: AI 판정

**What to build:** 수치 검증과 축 반응을 통과한 구성기를, 슬라이더 끝값과 쌍별 모서리 조합에서 렌더링해 VLM이 뚫림·겹침·비례 깨짐을 판정한다. 실패는 `ai_judgment` 피드백으로 명세 작성에 돌아가고, 판정만 3번 실패하면 이유를 붙여 최종 승인으로 넘어간다.

**Blocked by:** 06 (축 반응 검증), 15 (LiteLLM 포트와 실제 명세 작성)

**Status:** ready-for-agent

- [ ] 검증기가 슬라이더 끝값과 쌍별 모서리 조합의 렌더링 이미지를 만든다
- [ ] AI 판정이 수치 검증·축 반응을 통과한 뒤에만 돈다
- [ ] 판정 결과가 JSON Schema 형식이고, 실패는 이미지 경로와 이유 한 줄을 담은 `ai_judgment` 피드백이 된다
- [ ] 수치·축 반응은 통과했는데 판정만 3번 실패하면, 판정 이유를 붙인 채 최종 승인으로 넘어간다
- [ ] 최종 승인 화면에 넘어온 판정 이유가 표시된다
