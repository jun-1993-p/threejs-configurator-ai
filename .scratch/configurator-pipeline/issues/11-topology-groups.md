# 11: 위상 묶음

**What to build:** 연속 슬라이더가 범위 안에서 위상 경계를 넘으면(예: 폭이 커지며 칸막이 수가 늘어남), 스윕을 위상 묶음으로 나누고 변형 엔진은 같은 묶음 안에서만 섞으며 경계에서 형상을 바로 바꾼다(ADR-0005). 쇼핑몰 고객은 슬라이더를 매끄럽게 움직이는 동안 칸막이가 한 번에 나타나는 것을 본다.

**Blocked by:** 07 (여러 슬라이더 덧셈), 10 (개수형 제외와 범위 끝 위상 축소)

**Status:** ready-for-agent

- [ ] 애드인이 범위 안의 위상 경계를 찾아 스윕을 위상 묶음으로 나누고, 묶음마다 나머지 슬라이더의 단독 스윕을 뽑는다
- [ ] 변형 엔진이 같은 위상 묶음 안에서만 이동량을 섞고, 경계에서는 페이드 없이 바로 바꾼다
- [ ] 파라미터 하나당 위상 묶음이 4개를 넘으면 범위를 줄이라는 피드백이 나온다
- [ ] 위상 묶음은 명세에 적히지 않는다
- [ ] 칸막이 수가 바뀌는 실제 상품의 녹화본으로 엔진 테스트가 있다
