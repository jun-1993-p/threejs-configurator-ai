# 20: 최종 승인 편집과 반려

**What to build:** 운영자가 최종 승인에서 구성기를 직접 조작해 보며 슬라이더 이름을 고치고 범위를 좁힐 수 있다. 반려하면 다른 후보를 고르러 후보 선택으로 돌아가거나, 거절 이유를 한 줄 적어 후보 제시를 다시 할 수 있다.

**Blocked by:** 16 (정보 입력, 후보 제시·선택)

**Status:** ready-for-agent

- [ ] 최종 승인 화면에서 슬라이더 이름을 고치면 명세에 반영된다
- [ ] 범위는 좁히기만 할 수 있고, 넓히려 하면 막힌다
- [ ] 반려 후 "다른 후보"를 고르면 이미 받은 후보로 후보 선택에 돌아간다
- [ ] 반려 후 거절 이유를 적으면 그 문장이 후보 제시 입력에 들어가 새 후보 2~4개가 만들어진다
- [ ] 고친 내용과 거절 이유가 처리 기록에 남는다
