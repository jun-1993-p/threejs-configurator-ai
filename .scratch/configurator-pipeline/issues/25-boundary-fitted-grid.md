# 25: 경계 맞춤 격자

**What to build:** 면의 점을 매개변수 범위 격자 대신 경계 맞춤 격자로 둔다(ADR-0016). 경계 모서리 위의 점은 모서리와 그 위의 비율로, 안쪽 점은 기본 형상에서 정한 경계 기준 상대 위치로 정한다. 연결 정보는 기본 형상에서 한 번 만들어 업로드 묶음에 담는다. 그러면 구멍 있는 판재나 둥근 상판도 슬라이더를 움직이는 동안 가장자리가 정확하게 따라온다.

**Blocked by:** 24 (SolidCraft 합성 녹화본)

**Status:** ready-for-human

- [x] 티켓 24에서 선택 필드로 넣은 면 이름과 모서리 이름(두 면 이름 쌍, 같은 쌍이 여럿이면 순번)이 필수가 되고, 기본 형상 연결 정보가 들어가며, 서버의 "면마다 n×n 점" 검사가 새 형식 검사로 바뀐다
- [x] 샘플 사이의 면은 이름으로 짝짓고, 기하 대조(법선·중심)는 확인용으로만 쓴다. 짝이 하나로 정해지지 않으면 위상 변화로 처리한다
- [x] 트림 여부를 따로 판정하지 않고 모든 면에 같은 방식을 쓴다
- [x] 서랍장 합성 녹화본의 10단계(`body_d` 5단계, `d6` 5단계)에서 고리 모양 서랍 테두리를 포함한 모든 면의 점 수·순서가 같다
- [x] 모든 점이 면 안(경계 포함)에 있다
- [x] 이동은 바뀐 파라미터의 축으로만 일어나고, 다른 축의 이동은 1e-6 mm 이하다
- [ ] **(사람 확인)** Fusion 애드인에서 피처 기준 면 이름을 만들 수 있는지, 같은 방식으로 점을 추출할 수 있는지 확인한다

### 2026-10-29 구현 (SolidCraft 쪽)

- 코드: `synthetic/fitted.py`(배치 만들기 `build_layout`, 놓기 `place`), `synthetic/solidcraft_model.py`가 이를 쓴다. 이전 n×n 격자(`synthetic/grid.py`)는 지웠다.
- **안쪽 점의 상대 위치**: 기본 형상에서 경계 점만으로 면을 삼각형으로 나누고(구멍은 이음선으로 이은 귀 자르기), 안쪽 점마다 감싸는 삼각형의 무게중심 좌표를 기억한다. 다른 샘플에서는 그 삼각형의 경계 점을 따라 같은 비율로 놓는다. 귀는 대각선이 가장 짧은 것부터 자른다. 그래야 폭이 좁은 띠(서랍 윗테두리)에서 삼각형이 띠의 양쪽 변만 이어, 띠 길이가 바뀌어도 뒤집히지 않는다.
- **원기둥**: 같은 계산을 (각도 × 반지름, 높이) 평면에서 하고 원기둥 위로 되돌린다. 각도는 경계 각도 사이 가장 큰 빈틈의 가운데에서 잘라 펼친다.
- **밀도 규칙**: 점 간격 h = 바디 바운딩 박스 대각선 / (2(n-1)), n = `GRID_N` = 9. 모서리는 ceil(길이 / h)로 나누고, 원호는 15°마다 적어도 한 번 나눈다. 나누는 수는 모서리 하나로만 정하므로 같은 모서리를 공유하는 면은 그 위에 같은 점을 둔다. 안쪽 점은 간격 h의 격자 중 경계에서 h/4보다 먼 점이다. 기본 형상 기준으로 한 번 정한다. 서랍장은 샘플당 1,965점.
- **서버**: `server/bundle.py`의 `pair_faces`가 (바디, 면 이름)으로 짝짓고 표면 종류와 법선(원기둥은 축)으로 확인한다. 짝이 하나로 정해지지 않는 샘플은 거절하지 않고 `sample_topology`에서 `changed`로 알린다(티켓 10, 11이 쓴다). 짝지어진 면은 점 수가 기본 형상과 같아야 한다.
- **스키마**: 면 `name`, 샘플·기본 형상 `edges`가 필수가 됐고, 기본 형상 면에는 `triangles`가 필수다. 연결은 기본 형상에만 담는다. 기존 n×n 녹화본은 더 이상 유효하지 않다.
- **확인**: `synthetic/tests/test_fitted_recording.py`가 실제 solidcraft-cli로 서랍장(`body_d`, `d6` 각 5단계)의 점 수·순서, 면 안 여부(고리 모양 서랍 테두리 포함), 축 밖 이동 1e-6 mm 이하, 삼각형 뒤집힘 없음을 확인한다. 구멍·필렛·통 원기둥이 있는 판재(원기둥 면 5개)도 `w`, `hd` 스윕에서 점 수가 같고 점이 원기둥 위에 있다.
- `fixtures/synthetic/drawer.json`을 새 형식으로 다시 만들었다(2.3 MB).
- **Fusion 애드인**: `fusion_model.py`의 `sample_edges`가 `NotImplementedError`를 낸다. 지금 Fusion 업로드는 막혀 있다(`addin/README.md`에 적음). 사람 확인 항목이 남아 있어 상태는 `ready-for-human`.
