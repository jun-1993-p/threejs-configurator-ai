# 25: 경계 맞춤 격자

**What to build:** 면의 점을 매개변수 범위 격자 대신 경계 맞춤 격자로 둔다(ADR-0016). 경계 모서리 위의 점은 모서리와 그 위의 비율로, 안쪽 점은 기본 형상에서 정한 경계 기준 상대 위치로 정한다. 연결 정보는 기본 형상에서 한 번 만들어 업로드 묶음에 담는다. 그러면 구멍 있는 판재나 둥근 상판도 슬라이더를 움직이는 동안 가장자리가 정확하게 따라온다.

**Blocked by:** 24 (SolidCraft 합성 녹화본)

**Status:** ready-for-agent

- [ ] 티켓 24에서 선택 필드로 넣은 면 이름과 모서리 이름(두 면 이름 쌍, 같은 쌍이 여럿이면 순번)이 필수가 되고, 기본 형상 연결 정보가 들어가며, 서버의 "면마다 n×n 점" 검사가 새 형식 검사로 바뀐다
- [ ] 샘플 사이의 면은 이름으로 짝짓고, 기하 대조(법선·중심)는 확인용으로만 쓴다. 짝이 하나로 정해지지 않으면 위상 변화로 처리한다
- [ ] 트림 여부를 따로 판정하지 않고 모든 면에 같은 방식을 쓴다
- [ ] 서랍장 합성 녹화본의 10단계(`body_d` 5단계, `d6` 5단계)에서 고리 모양 서랍 테두리를 포함한 모든 면의 점 수·순서가 같다
- [ ] 모든 점이 면 안(경계 포함)에 있다
- [ ] 이동은 바뀐 파라미터의 축으로만 일어나고, 다른 축의 이동은 1e-6 mm 이하다
- [ ] **(사람 확인)** Fusion 애드인에서 피처 기준 면 이름을 만들 수 있는지, 같은 방식으로 점을 추출할 수 있는지 확인한다
