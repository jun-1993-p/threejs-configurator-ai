# 04: 수치 검증과 검증 피드백 루프

**What to build:** 조립된 구성기를 검증점에서 녹화된 Fusion 형상과 비교해, 치수 오차와 형상 오차가 합격선 안인지 판정한다(ADR-0012). 실패하면 검증 피드백 형식으로 명세 작성에 돌려보내 재시도하고, 같은 후보로 3번 넘게 실패하면 실패 이유를 붙여 후보 제시로 돌아간다.

**Blocked by:** 03 (파이프라인 실행기 관통)

**Status:** ready-for-agent

- [ ] 검증점(스윕 샘플 사이 값)의 Fusion 형상이 업로드 묶음에 담기거나 녹화본에 있다
- [ ] 부품별 W·D·H와 두께의 치수 오차가 0.2 mm를 넘으면 실패한다
- [ ] 꼭짓점 단위 형상 오차가 max(1 mm, 바운딩 박스 대각선의 0.1%)를 넘으면 실패한다
- [ ] 실패는 `path`·`slider`·`part`·`kind`·`measured`·`expected`·`hint` 형식으로 나오고, 힌트는 규칙으로 만들어진다
- [ ] 피드백이 명세 작성으로 돌아가 재시도되고, 같은 후보로 3번 넘게 실패하면 이유를 붙여 후보 제시로 간다
- [ ] 각본 AI가 일부러 틀린 명세를 내는 경계 1 테스트로 재시도와 3회 제한을 확인한다
