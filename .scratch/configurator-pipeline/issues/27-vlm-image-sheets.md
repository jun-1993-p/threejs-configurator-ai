# 27: VLM에 보내는 그림을 모음 그림으로 묶기

**What to build:** 부품 탐색과 AI 판정이 VLM에 보내는 그림을, 칸을 격자로 이어 붙인 모음 그림으로 보낸다. 요청 하나에 붙는 그림 수가 VLM의 그림 수 제한을 넘지 않게 한다. Groq VLM(`qwen/qwen3.8-27b`)은 요청 하나에 3장까지만 받는데, 지금 부품 탐색은 6장을, AI 판정은 2n + 4·C(n,2)장을 보내 첫 단계에서 멈춘다(티켓 26 6절 실행 기록).

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 부품 탐색의 여섯 방향 그림이 모음 그림 한 장으로 간다. 문장에 칸 배치(몇째 줄 몇째 칸이 어느 방향에서 본 그림인지)가 적힌다
- [ ] AI 판정 렌더링이 모음 그림으로 묶여 간다. 문장에 칸마다 렌더링 이름과 슬라이더 값이 적히고, 답의 `image`는 지금처럼 렌더링 이름이다
- [ ] 요청 하나의 그림 수가 VLM 그림 수 제한(설정값, 기본 3)을 넘지 않는다. 모음 그림이 그보다 많으면 AI 판정을 나눠 묻고 문제 목록을 합친다(티켓 23에서 옮김)
- [ ] 같은 축척으로 그린 렌더링은 모음 그림에서도 같은 축척이다(슬라이더 끝값끼리 크기 차이가 보여야 한다)
- [ ] 실행기의 단계·형식 검사·다시 묻기는 바뀌지 않는다. 그림을 묶는 일은 LiteLLM 포트 안에서 끝난다
