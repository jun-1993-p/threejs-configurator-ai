# 16: 정보 입력, 후보 제시·선택

**What to build:** 운영자가 정보 입력(상품명, 상품 종류, 원하는 슬라이더와 범위 메모, 두께 선택 노출 여부)을 적으면, AI가 명세 작성 전에 슬라이더 구성 후보 2~4개를 업로드한 스윕으로 만든 미리보기와 함께 보여주고, 운영자가 하나를 고른다.

**Blocked by:** 15 (LiteLLM 포트와 실제 명세 작성)

**Status:** ready-for-agent

- [ ] 정보 입력 화면에 상품명, 상품 종류(목록), 범위 메모(자유 문장), 두께 선택 노출 여부(기본 "AI 판단")가 있고 직업 항목은 없다
- [ ] 후보 제시가 JSON Schema 형식의 후보 2~4개를 내고, 부품 탐색은 VLM이 맡는다
- [ ] 후보끼리 정면·노출할 부모 파라미터·두께 선택 노출 여부 중 하나 이상이 다르지 않으면 다시 만든다
- [ ] 후보 카드마다 업로드 스윕으로 만든 실제 변형 미리보기와, 다른 후보와의 차이 한 줄, 정면에 따른 W·D·H 축 대응이 표시된다
- [ ] AI가 정면을 확신하지 못하면 후보끼리 정면이 다르다
- [ ] 운영자가 고른 후보가 명세 작성의 입력이 된다
