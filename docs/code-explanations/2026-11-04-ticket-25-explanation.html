티켓 25: 경계 맞춤 격자 (SolidCraft 쪽)

면의 점을 매개변수 범위 격자 대신, 면 경계에 맞춘 점으로 바꾼다. 모서리 위의 점과 경계에 대한 상대 위치로 정한 안쪽 점으로 이루어지며, 구멍이 있는 면에서도 점이 면 밖으로 나가지 않는다. 이 티켓은 SolidCraft 합성 녹화본과 서버 검사 쪽을 다루고, Fusion 쪽은 사람 확인이 남았다.

jun-1993-p/threejs-configurator-ai 티켓 25 (커밋 eba2692, 배경 결정 b60d054의 ADR-0016) at eba2692, explained 2026-11-04. References link to this commit.

배경

스윕, 꼭짓점 짝짓기, 위상 변화가 낯설다면 펼쳐서 읽는다.

구성기는 브라우저에서 CAD 모델을 다시 계산하지 못한다. 대신 업로드 때 파라미터 값을 바꿔 가며 뽑아 둔 형상 표본(스윕)을 받아, 슬라이더 위치에 맞게 표본 사이를 섞는다(ADR-0002). 섞으려면 표본 A의 꼭짓점 하나와 표본 B의 꼭짓점 하나가 같은 곳을 가리켜야 한다. 이 1:1 짝이 "꼭짓점 짝짓기"다.

짝이 맞으려면 같은 면 구성의 표본끼리 점 개수와 순서가 같아야 한다. 면 구성이 바뀌는 지점(예: 폭이 늘자 칸막이가 하나 더 생김)은 위상 변화이고, 그런 표본은 따로 묶어서 다룬다(ADR-0005).

티켓 01과 24까지의 방식은 면의 매개변수 범위(u,v)에 n×n 격자를 찍는 것이었다. 사각 판이면 점이 전부 면 위에 놓이지만, ADR-0016이 지적하는 문제는 트림된 면(구멍 있는 판, 원형 상판)이다. 매개변수 범위는 트림 전 표면의 사각 범위라서 일부 점이 면 밖의 표면 위에 찍힌다. ADR에는 이 문제의 구체적인 사례가 있다. 폭 18 mm 고리 모양 서랍 테두리의 점 수가 서랍 깊이에 따라 58개씩 늘고 줄었다. 바깥 범위 비율로 깐 격자선이 고정 폭 테두리와 구멍 사이를 넘나들기 때문이다.

ADR-0016은 ADR-0002의 "꼭짓점 짝짓기" 절을 대체하는 결정이다. 용어집은 이 결과를 경계 맞춤 격자라 부른다.

핵심 개념 경계 맞춤 격자: 한 면의 점 집합으로, 경계 모서리 위의 점과 경계에 대한 상대 위치로 정한 안쪽 점으로 이루어진다. 연결(삼각형)은 기본 형상에서 한 번 정한다. 샘플 사이의 꼭짓점 짝은 이 점들의 번호로 정해진다.

이 티켓 이름 뒤의 "SolidCraft 쪽"이라는 말은 범위를 뜻한다. Fusion에서 같은 이름과 점을 만드는 일은 사람 확인이 필요해 남겨 두었다(티켓 파일의 마지막 미완 항목).

핵심 아이디어

핵심은 "점의 번호가 곧 짝"이게 만드는 것이다. 기본 형상에서 면마다 배치(어떤 점을 어떤 규칙으로 만들지의 목록)를 한 번 만들어 두고, 이후 모든 샘플에서는 같은 이름의 면에 그 배치를 그대로 놓는다. 점의 개수와 순서는 배치가 정하므로 샘플이 달라도 같다.

점의 규칙은 두 종류다.

  • 경계 점: "모서리 e의 비율 t 위치"다. 예를 들어 길이 120 mm 모서리를 점 간격 50 mm로 나누면 ceil(120/50) = 3등분이라 t = 0, 1/3, 2/3에 점이 생긴다(끝점은 이어지는 모서리의 시작점이다). 샘플에서 모서리가 180 mm가 되어도 규칙은 같은 t이므로 점이 늘어나지 않고 모서리를 따라 벌어진다. 나누는 수는 그 모서리 하나만으로 정해지기 때문에, 같은 모서리를 공유하는 두 면은 그 위에 같은 점을 둔다.
  • 안쪽 점: "경계 점 셋과 무게중심 좌표"다. 기본 형상에서 경계 점만으로 면을 삼각형으로 나눈 뒤, 안쪽 점마다 그 점을 감싸는 삼각형 안의 비율을 기억한다.

무게중심 좌표로 안쪽 점이 어떻게 따라가는지 장난감 수치로 보자. 기본 형상의 삼각형이 A(0, 0), B(100, 0), C(0, 40)이고 안쪽 점이 q = (25, 10)이라면 무게는 (0.5, 0.25, 0.25)다(0.5·A + 0.25·B + 0.25·C = (25, 10)). 다른 샘플에서 C가 (0, 80)으로 올라가면 q는 0.5·(0, 0) + 0.25·(100, 0) + 0.25·(0, 80) = (25, 20)에 놓인다. 삼각형이 뒤집히지 않는 한 점은 삼각형 안에 머문다. 삼각형 꼭짓점이 모두 경계 위에 있으므로 면 안에 머문다는 보장이 따라온다는 것이 모듈 설명의 논리다.

한 면의 점이 만들어지고 놓이는 흐름(예시 데이터)

서버는 이름으로 면을 짝짓는다. 짝은 이름이 같으면서 표면 종류와 방향도 맞아야 한다. 짝이 하나로 정해지지 않는 샘플은 거절하지 않고 위상 변화(changed)로 알린다. 이 처리는 티켓 10과 11이 쓸 것이라고 코드 주석이 적었다.

기존 녹화본은 더 이상 유효하지 않다 면 name과 샘플별 edges, 기본 형상 면의 triangles가 필수가 되었다. 티켓 구현 기록은 기존 n×n 녹화본이 새 스키마를 통과하지 못한다고 적었고, 그래서 fixtures/synthetic/drawer.json을 새 형식으로 다시 만들었다. Fusion 어댑터의 sample_edges는 NotImplementedError를 내므로 지금 Fusion 업로드는 막혀 있다.

코드 따라가기

흐름: 스키마(필수 필드) → 애드인 핵심(모서리와 연결 포함) → SolidCraft 어댑터(점 간격, 배치 기억) → 경계 점과 안쪽 점 계산(fitted.py) → 서버의 이름 짝짓기와 점 수 검사.

1. 계약: 스키마가 필수로 바꾼 것

티켓 24에서 선택이던 필드가 필수가 되었다. 면은 name이 필수이고(schema/upload-bundle.schema.json:104), 샘플은 edges를 필수로 담으며(schema/upload-bundle.schema.json:85), 기본 형상의 면은 거기에 더해 triangles를 필수로 담는다(schema/upload-bundle.schema.json:60). 연결 정보를 기본 형상에만 두는 것이 "연결은 한 번만 정한다"의 형식이다.

3. SolidCraft 어댑터: 간격을 정하고 배치를 기억한다

점 간격은 바디 바운딩 박스 대각선을 2(n-1)로 나눈 값이다(n = GRID_N = 9이므로 대각선/16). 대각선은 어댑터가 만들어질 때 재서 모든 샘플에 같게 쓴다(synthetic/solidcraft_model.py:95-96). 배치는 (바디, 면 이름)을 열쇠로 처음 본 순간에 만들고 이후에는 재사용한다.

주석대로 기본 형상에 없던 이름의 면은 그 샘플에서 새 배치를 얻는다. 어댑터가 처음 만나는 형상이 기본 형상이므로 첫 호출이 곧 기본 형상 배치를 만든다. 간격에 쓰는 대각선과 면 경계(bound)는 이름을 열쇠로 한 모서리 딕셔너리로 바뀌었다(synthetic/solidcraft_model.py:158). 경계 점의 규칙이 모서리를 이름으로 가리키기 때문이다.

4. 경계 점: 모서리를 이어 고리를 만들고 비율로 나눈다

배치를 만들 때 먼저 모서리를 끝점끼리 이어 닫힌 고리로 묶는다. 구멍이 있는 면이면 고리가 둘 이상이다. 고리마다 모서리를 edge_segments만큼 나눠 (모서리 이름, 비율 t) 규칙을 만든다. 모서리를 거꾸로 지나가면 t가 1 - i/k가 된다.

synthetic/fitted.py:146-152

def edge_segments(e: Edge, spacing: float) -> int:
    """모서리를 나누는 수. 모서리 하나로만 정해진다."""
    count = max(1, math.ceil(edge_length(e) / spacing - 1e-9))
    arc = _arc(e)
    if arc is not None:
        count = max(count, math.ceil(arc.sweep / MAX_ARC_STEP - 1e-9))
    return count

원호 모서리는 길이 기준에 더해 MAX_ARC_STEP(15°)마다 적어도 한 번 나눈다. 곡선이 너무 성기게 잘리지 않게 하려는 규칙이다. 원호의 모양은 시작, 중간, 끝 세 점으로 알아낸다(synthetic/fitted.py:111-127).

def _loops(edges: dict[str, Edge], spacing: float) -> list[list[PointSpec]]:
    """모서리를 끝점으로 이어 고리로 만들고, 고리마다 경계 점 규칙을 순서대로 낸다."""
    scale = max(edge_length(e) for e in edges.values()) or 1.0
    tol = 1e-6 * scale

    def same(p: Vec, q: Vec) -> bool:
        d = _sub(p, q)
        return math.sqrt(_dot(d, d)) <= tol

    unused = dict(edges)
    loops = []
    while unused:
        name, e = next(iter(unused.items()))
        del unused[name]
        chain = [(name, e, True)]
        start, cur = e.start, e.end
        while not same(cur, start):
            nxt = next(((n, x, True) for n, x in unused.items() if same(x.start, cur)), None) or next(
                ((n, x, False) for n, x in unused.items() if same(x.end, cur)), None
            )
            if nxt is None:
                raise ValueError(f"모서리 {name}에서 시작한 경계가 닫히지 않습니다")
            del unused[nxt[0]]
            chain.append(nxt)
            cur = nxt[1].end if nxt[2] else nxt[1].start
        specs = []
        for n, x, forward in chain:
            k = edge_segments(x, spacing)
            for i in range(k):
                specs.append(PointSpec(kind="boundary", edge=n, t=i / k if forward else 1 - i / k))
        loops.append(specs)
    return loops

5. 면을 삼각형으로 나누고 안쪽 점을 얻는다

build_layout은 경계 점을 면의 2차원 좌표(평면은 (u,v), 원기둥은 (각도×반지름, 높이))로 옮기고, 넓이가 가장 큰 고리를 바깥 고리, 나머지를 구멍으로 본다. 구멍은 이음선으로 바깥 고리에 이어 하나의 고리로 만든 뒤 귀 자르기로 삼각형을 얻는다. 이 삼각형 꼭짓점은 모두 경계 점이다.

synthetic/fitted.py:369-392

def build_layout(surface: Surface, edges: dict[str, Edge], spacing: float) -> FaceLayout:
    """기본 형상의 면 하나에 대한 경계 맞춤 격자 배치."""
    loops = _loops(edges, spacing)
    specs = [s for loop in loops for s in loop]
    pts3 = [_boundary_point(s, edges) for s in specs]
    cut = _cylinder_cut(surface, pts3) if isinstance(surface, Cylinder) else 0.0
    chart = _Chart(surface, pts3[0], cut)
    pts = [chart.to2d(p) for p in pts3]

    index_loops, offset = [], 0
    for loop in loops:
        index_loops.append(list(range(offset, offset + len(loop))))
        offset += len(loop)
    index_loops.sort(key=lambda lp: -abs(_signed_area(lp, pts)))
    outer, holes = index_loops[0], index_loops[1:]
    if _signed_area(outer, pts) < 0:
        outer.reverse()
    for h in holes:
        if _signed_area(h, pts) > 0:
            h.reverse()
    poly = outer
    for h in sorted(holes, key=lambda lp: -max(pts[i][0] for i in lp)):
        poly = _bridge(poly, h, pts)
    boundary_tris = _earcut(poly, pts)

귀 자르기는 자를 수 있는 귀 중 대각선이 가장 짧은 것부터 자른다. 코드 주석은 이유를 이렇게 적었다. 폭이 좁은 띠에서 삼각형이 띠의 양쪽 변만 이어, 띠의 길이가 바뀌어도 삼각형이 뒤집히지 않는다.

    잇게 되어, 띠의 길이가 바뀌어도 삼각형이 뒤집히지 않는다.

원기둥은 같은 계산을 (각도×반지름, 높이) 평면에서 하고 원기둥 위로 되돌린다. 각도는 경계 각도 사이의 가장 큰 빈틈 한가운데에서 잘라 펼친다(synthetic/fitted.py:187-197).

def pair_faces(baseline: list[dict[str, Any]], sample: list[dict[str, Any]]) -> list[int] | None:
    """샘플의 면마다 짝인 기본 형상 면의 번호. 짝이 하나로 정해지지 않으면 None(위상 변화)."""

퀴즈

경계 점을 몇 개로 나눌지는 면이 아니라 모서리 하나의 길이와 모양만으로 정한다. 이 설계의 이유로 가장 알맞은 것은?

나누는 수가 면마다 달라지면 맞닿은 두 면이 그 모서리 위에서 서로 다른 점을 갖게 되어 틈이 생긴다. 모서리 하나로만 정하면 양쪽 면의 점이 겹친다. 길이가 입력이 되는 것은 사실이지만 "모서리 하나로만"이라는 제한의 이유는 아니다.

기본 형상의 삼각형이 A(0, 0), B(100, 0), C(0, 40)이고 안쪽 점의 무게가 (0.5, 0.25, 0.25)다. 다른 샘플에서 C만 (0, 80)으로 올라가면 이 점은 어디에 놓일까?

점은 세 꼭짓점의 가중합 0.5·A + 0.25·B + 0.25·C로 놓인다. B와 A는 그대로이므로 x는 25이고, y는 0.25 × 80 = 20이다. 점이 제자리에 남지 않고 경계를 따라 움직인다는 것이 이 방식의 요점이다.

귀 자르기가 대각선이 가장 짧은 귀부터 자르는 이유로 가장 알맞은 것은?

띠 모양 면(서랍 윗테두리)에서 긴 대각선 삼각형은 띠의 길이가 바뀔 때 뒤집힐 수 있다. 짧은 대각선부터 자르면 삼각형이 띠의 양쪽 변을 잇는 모양이 되어 길이가 바뀌어도 형태가 유지된다. 어느 순서로 잘라도 삼각형 수는 같다.

샘플 면의 이름과 표면 종류는 기본 형상과 같은데 법선이 정반대다. sample_topology는 이 샘플을 어떻게 표시할까?

평면 법선은 방향까지 비교해 0.999 이상 나란해야 하므로 짝이 없다고 판정되고, pair_faces가 None을 돌려준다. failed는 재계산 상태가 ok가 아닐 때만 붙는다.

이름은 모두 짝지어졌는데 한 면의 점 수가 기본 형상과 다르다. 서버는 이 묶음을 어떻게 다룰까?

위상 변화는 면 이름 집합이나 표면이 어긋날 때의 이야기다. 이름이 모두 짝지어졌다면 같은 배치를 놓은 결과이므로 점 수가 같아야 하고, 다르면 만든 쪽의 버그이므로 거절한다.
