# 스윕은 업로드 때 애드인이 적응형으로 뽑는다

계획서 순서상 후보 제시가 명세 작성보다 먼저이므로, 스윕은 슬라이더 범위가 정해지기 전인 업로드 때 끝나야 한다. 그래서 CAD 애드인은 사용자 파라미터 전부를 기본값 ±50%의 넉넉한 범위로 스윕하고, 재계산 실패·위상 한계 지점에서 스윕 범위를 줄인다. 샘플은 파라미터마다 5점 균등에서 시작해 구간 중간 검증점의 오차가 합격선을 넘는 구간만 반으로 나누어 늘린다. 상한을 넘어도 합격선을 못 맞추면 그 파라미터는 실패로 보고한다. 이 스윕은 후보 미리보기에도 그대로 쓰여, 사람이 실제 변형을 보고 고를 수 있다. 샘플 위치는 AI가 정하지 않는다.

## Considered Options

- 명세를 먼저 쓰고 그 범위로 스윕한 뒤 검증된 명세만 후보로 보여주기: 사람이 고르기 전에 후보 수만큼 비싼 스윕·검증을 돌려야 하고, 계획서 순서와 맞지 않는다.
- 고정 균등 샘플: 경사·원형 패턴 같은 비선형 구간을 놓친다.
