# 위상 변화는 위상 묶음으로 나눠 다룬다

꼭짓점 수가 바뀌면 이동량을 섞을 수 없으므로 세 가지를 함께 쓴다. 개수형 파라미터는 슬라이더로 직접 노출하지 않는다. 연속 슬라이더가 범위 끝에서 위상을 깨면 그 지점에서 범위를 줄이고 이유를 검증 피드백으로 남긴다. 연속 슬라이더가 범위 안에서 위상 경계를 넘으면(예: 폭이 커지며 칸막이 수가 늘어남) 스윕을 위상 묶음으로 나누고, 이동량은 같은 묶음 안에서만 섞는다. OBJ 입력과 범용화를 미룬다는 ADR-0002와는 별개로, 위상 묶음은 CAD 애드인 입력 안에서 처리한다.

## Consequences

- 위상 경계에서 형상은 페이드 없이 바로 바뀐다. 슬라이더는 매끄럽게 계속 움직인다.
- 위상 묶음마다 나머지 슬라이더의 단독 스윕을 따로 뽑아야 하므로, 슬라이더 하나당 위상 묶음은 4개까지로 한다. 넘으면 범위를 줄이라는 검증 피드백을 낸다.
