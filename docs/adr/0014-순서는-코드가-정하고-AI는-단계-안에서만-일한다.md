# 순서는 코드가 정하고 AI는 단계 안에서만 일한다

파이프라인의 단계 순서(업로드 → 정보 입력 → 후보 제시 → 후보 선택 → UI 스타일 → 명세 작성 → 조립 → 검증 → 최종 승인 → 제출·기록)와 실패 시 돌아가는 경로는 코드에 고정한다. AI는 정해진 단계 안에서 정해진 입력을 받아 정해진 형식(JSON Schema)으로만 답한다. 에이전트가 스스로 다음 단계나 도구를 고르게 하면 같은 상품도 실행마다 경로가 달라져 재현과 검증이 어렵고, 1인 프로젝트에서 실패 원인을 추적하기 힘들다. 그래서 유연성을 포기하고 예측 가능성을 택한다. 단계를 추가하거나 순서를 바꾸는 것은 코드 변경이다.
