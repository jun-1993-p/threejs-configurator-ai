# 변형은 스윕 결과의 꼭짓점 이동량을 섞는 방식으로 한다

**변형 엔진**은 **스윕** 결과 사이의 꼭짓점 이동량을 슬라이더 값에 따라 섞어(블렌드) 모델을 변형한다. 임의 OBJ 파일을 직접 다루는 범용 변형은 범용화 단계로 미룬다.

## 이유

- 스윕 결과는 같은 위상(꼭짓점 대응)을 가지므로 이동량 혼합이 단순하고 빠르다.
- Fusion 파라미터가 만든 형상을 그대로 재현하므로 **두께 고정** 같은 제약을 스윕 단계에서 보장할 수 있다.

## 결과

- 지금은 스윕을 거친 상품만 지원한다. OBJ 직접 입력은 지원하지 않는다.
- 범용화 단계에서 이 결정을 다시 연다.

## 꼭짓점 짝짓기

Fusion 메쉬 출력은 크기에 따라 곡면(필렛·둥근 모서리)의 삼각형 수가 달라져서, 위상이 같아도 꼭짓점이 1:1로 짝지어지지 않는다. 그래서 애드인은 메쉬 출력을 쓰지 않고 면마다 매개변수(u,v) 격자로 직접 점을 찍는다. 짝은 "면 + (u,v)"로 정해지므로, B-rep 면 구성이 같으면 꼭짓점 수가 항상 같다. 메쉬 각도 기준만 쓰는 방법은 같은 수를 보장하지 않고, 기본 메쉬 꼭짓점을 가장 가까운 표면 점으로 옮겨 짝을 만드는 방법은 크게 변형될 때 짝이 엇갈린다. 면별 격자 밀도 규칙은 애드인 구현 때 정한다.
