# 애드인은 최종 승인까지 서버에 연결된 채로 둔다

업로드 뒤에도 교차 검증 샘플, 격자 보강, 두께 선택 후보 형상은 Fusion이 새로 계산해야 한다. 어떤 슬라이더 쌍이 필요한지는 후보 선택 뒤에야 정해진다. 그래서 업로드부터 최종 승인까지 CAD 애드인을 서버에 연결해 두고, 검증 중에 서버가 추가 샘플을 요청한다. 업로드 때 모든 파라미터 쌍(n(n−1)/2)과 두께 후보를 미리 뽑는 방법은 업로드를 크게 늦춘다. 1인 운영·LAN 로컬 서버이므로 Fusion을 켜 두는 부담은 작다. 연결이 끊기면 검증을 멈추고 "Fusion 연결 필요"를 표시한다.

Fusion을 껐다 켜도 이어지게, 애드인은 업로드 ID를 업로드한 디자인 문서의 속성에 적어 둔다(면 표시와 같은 곳이라 문서를 저장하면 따라온다). 다시 켠 뒤 그 문서가 열려 있고 서버가 그 업로드를 알면 애드인이 알아서 이어 답한다. 업로드 뒤 문서를 저장하지 않고 끄면 ID가 사라져 이어지지 않는다. 처음 확인한 결과(티켓 26 3절)는 ID를 메모리에만 두었을 때 다시 켠 뒤 이어지지 않았다.
