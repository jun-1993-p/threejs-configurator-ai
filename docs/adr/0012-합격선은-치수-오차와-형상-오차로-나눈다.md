# 합격선은 치수 오차와 형상 오차로 나눈다

계획서는 정확도를 "CAD 형상 대비 0.2 mm 이하" 하나로 정했지만, 합격선을 둘로 나눈다. 부품별 W·D·H와 두께의 치수 오차는 0.2 mm로 하고, 꼭짓점 단위의 형상 오차는 1 mm와 바운딩 박스 대각선의 0.1% 중 큰 값으로 한다. 고객이 숫자로 보는 치수는 정확해야 하지만, 곡면 꼭짓점까지 0.2 mm를 요구하면 화면 1 px의 약 1/10을 맞추느라 샘플과 격자 보강이 크게 늘어 상품이 막힌다. 부품 치수는 슬라이더 값에 거의 선형으로 따라가므로 덧셈으로도 0.2 mm를 쉽게 맞춘다. 적응형 샘플 상한은 17점으로 둔다.
