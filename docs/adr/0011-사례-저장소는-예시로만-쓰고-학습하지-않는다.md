# 사례 저장소는 예시로만 쓰고 학습하지 않는다

후보 제시·명세 작성·AI 판정 때, 사례 저장소에서 같은 상품 종류로 거른 뒤 임베딩 유사도 상위 3개를 AI에게 예시로 준다. 미세조정이나 학습은 하지 않는다. 사례 기록은 나중에 학습에 쓸 수 있도록 JSONL로 남기지만, 1인 프로젝트에서 사례가 수십 개 수준이면 학습 비용에 견줄 효과가 없다. 예시 방식은 잘못된 사례를 빼기만 하면 바로 되돌릴 수 있다. 사례에는 최종 승인된 명세와 함께 선택되거나 버려진 후보, 최종 승인 때 사람이 고친 내용, 거절 이유를 남긴다. 사람이 고친 내용이 다음 명세를 개선하는 가장 큰 신호이기 때문이다.
