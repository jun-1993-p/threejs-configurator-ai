# 두께는 표준 두께 목록에서 앞뒤 한 칸을 고르게 한다

처음에는 두께를 완전히 고정하기로 했지만, 판재 두께를 고르고 싶어 하는 고객 요구가 있어 두께 선택을 둔다. 후보 값은 기본 두께 ±3 mm를 계산하지 않고, 고정 코어에 둔 한국 표준 두께 목록(3·6·9·12·15·18·24·30 mm)에서 기본 두께의 앞뒤 한 칸으로 정한다. 단순 ±3 mm로 계산하면 18t에서 21 mm처럼 주문할 수 없는 값이 나오기 때문이다. 두께는 여전히 연속 슬라이더로 바꾸지 않고, 슬라이더를 움직이는 동안에도 변하지 않는다(두께 고정).

## Consequences

- 고객에게는 1~2개(보통 몸통 판재)만 두께 선택으로 노출하고, 같은 두께를 쓰는 판재는 하나로 묶는다. 나머지 두께는 고정이다.
- 변형 엔진은 두께 후보마다 꼭짓점 이동량을 뽑아(사이 값 보간 없음) 다른 슬라이더와 덧셈으로 섞는다. 교차 검증과 격자 보강(ADR-0004, ADR-0008)이 그대로 적용된다.
- 목록 끝의 두께(3t, 30t)는 후보가 2개뿐이다.
