# 코어와 변형 엔진은 고정하고 AI는 상품별 JSON 명세만 쓴다

**고정 코어**와 **변형 엔진**은 사람이 관리하는 고정 코드로 두고, AI의 산출물은 상품마다 **명세(JSON)**와 **스타일 선택**(정해진 UI 스타일 목록에서 고르기)으로 한정한다.

## 이유

- AI가 임의의 코드를 생성하면 상품마다 동작이 달라지고 검증이 어렵다.
- 출력 범위를 JSON으로 좁히면 스키마 검증이 가능하고, 잘못된 결과가 구성기를 깨뜨리지 않는다.
- 1인 프로젝트에서 검토 부담을 줄인다.

## 결과

- 새 상품은 명세 작성과 **최종 승인**만으로 추가된다.
- 코어나 엔진이 못 하는 변형은 코어를 고치는 별도 결정이 필요하다.
