# 분류 라벨

스킬은 다섯 가지 표준 분류 역할로 말한다. 이 파일은 그 역할을 이 저장소에서 실제로 쓰는 라벨 문자열에 연결한다. 로컬 마크다운 트래커에서는 이슈 파일의 `Status:` 줄에 이 문자열을 적는다.

| mattpocock/skills의 라벨 | 이 저장소의 라벨 | 의미                              |
| ------------------------ | ---------------- | --------------------------------- |
| `needs-triage`           | `needs-triage`   | 검토가 필요한 이슈                |
| `needs-info`             | `needs-info`     | 보고자의 추가 정보를 기다리는 중  |
| `ready-for-agent`        | `ready-for-agent`| 충분히 명세되어 에이전트가 처리 가능 |
| `ready-for-human`        | `ready-for-human`| 사람이 직접 구현해야 함           |
| `wontfix`                | `wontfix`        | 처리하지 않음                     |

스킬이 역할을 언급하면(예: "AFK 가능 라벨 적용") 위 표의 해당 문자열을 쓴다.
